SECCIÓN 03

Conceptos previos

DEFINICIÓN · Selección Simple (if)

Evalúa una condición lógica. Si es verdadera, ejecuta un bloque de instrucciones; si es falsa, no realiza ninguna acción.

DEFINICIÓN · Selección Doble (if-else)

Evalúa una condición. Ejecuta un bloque si es verdadera y un bloque alternativo si es falsa.

DEFINICIÓN · Selección Múltiple (if-elif-else)

Evalúa varias condiciones en secuencia. Se ejecuta el primer bloque cuya condición resulte verdadera.

DEFINICIÓN · Condicionales Anidados

Estructuras condicionales ubicadas dentro del bloque de otra estructura condicional para evaluar decisiones jerárquicas.

def evaluar_triangulo(a, b, c):
    if (a + b > c) and (a + c > b) and (b + c > a):
        if a == b == c:
            return 'Triángulo Equilátero'
        elif a == b or a == c or b == c:
            return 'Triángulo Isósceles'
        else:
            return 'Triángulo Escaleno'
    return 'No forma un triángulo válido'

def calcular_imc(peso, estatura):
    imc = peso / (estatura ** 2)
    if imc < 18.5:
        cat = 'Bajo peso'
    elif imc < 25:
        cat = 'Normal'
    elif imc < 30:
        cat = 'Sobrepeso'
    else:
        cat = 'Obesidad'
    return f'IMC: {imc:.2f} - Categoría: {cat}'

print(calcular_imc(70, 1.75))
print(calcular_imc(95, 1.70))

SECCIÓN 07

Práctica en clase

Para cada uno de los siguientes 11 ejercicios, diseña el diagrama de flujo y escribe el código Python correspondiente:

  • 1. Mayoría de edad: Lee la edad y determina si es mayor de edad (>= 18) o menor.
  • 2. Número positivo, negativo o cero: Determina la polaridad de un número.
  • 3. Aprobación de una materia: Lee nota (0 a 100) y muestra 'Aprobado' (>= 51) o 'Reprobado'.
  • 4. El mayor de tres números: Determina el mayor de 3 números distintos usando condicionales anidados.
  • 5. Clasificación de un triángulo: Verifica validez (a+b>c) y clasifica en Equilátero, Isósceles o Escaleno.
  • 6. Descuento por compra: Monto final con descuentos (0% <100Bs, 5% 100-299.99Bs, 10% 300-699.99Bs, 15% >=700Bs).
  • 7. Año bisiesto: Determina si un año es bisiesto (divisible entre 4, excepto divisibles entre 100 no divisibles entre 400).
  • 8. Clasificación de IMC: Calcula IMC = peso / estatura² y clasifica en Bajo peso, Normal, Sobrepeso u Obesidad.
  • 9. Validación de contraseña: Verifica longitud >= 8, al menos un número y al menos una letra mayúscula.
  • 10. Calculadora básica con menú: Menú (1:suma, 2:resta, 3:multiplicación, 4:división) controlando división entre cero.
  • 11. Cuadrante de un punto: Determina cuadrante (I, II, III, IV), ejes u origen para coordenadas (x, y).
