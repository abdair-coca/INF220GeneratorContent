SECCIÓN 03

Conceptos previos

DEFINICIÓN · Función

Bloque de código con un nombre asignado que realiza una tarea específica y puede ser invocado múltiples veces desde diferentes partes de un programa.

DEFINICIÓN · Parámetro

Variable especificada en la definición de una función que recibe valores (argumentos) al momento de invocarla.

DEFINICIÓN · Retorno (Return)

Instrucción que finaliza la ejecución de la función y devuelve un resultado al punto donde fue llamada.

NOTA

Ámbito de variables (Scope): Una variable creada dentro de una función es local a ella y no existe fuera de su bloque de ejecución.

SECCIÓN 04

Diseño de Funciones en Python

En Python, la sintaxis básica para declarar una función incluye la palabra def, el nombre, los parámetros entre paréntesis y dos puntos:

  1. Definición del encabezado de la función con def y parámetros:

    def saludar(nombre):
    return f'¡Hola, {nombre}! BIenvenido a INF-220.'

  2. Invocación de la función pasando un argumento:

    mensaje = saludar('Estudiante')
print(mensaje)

    return numero % 2 == 0

    estado = 'Par' if es_par(n) else 'Impar'
    print(f'El número {n} es {estado}')
