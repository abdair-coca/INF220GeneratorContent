# 📚 Guías de Laboratorio — INF-220

Bienvenido. Estas son las guías interactivas de la materia **INF-220 ·
Programación Orientada a Objetos** (UATF · Facultad de Ciencias Puras · Ing.
Informática).

Las guías se ejecutan **directo en el navegador**: no necesitas descargar nada,
no necesitas instalar Python — los diagramas son interactivos (ampliables con
la rueda del ratón), las autoevaluaciones se corrigen solas y las celdas de
código Python corren en la página.

## ✨ Qué puedes hacer en cada guía

- **Diagramas interactivos**: amplía y desplaza cada figura de flujo con el ratón.
- **Autoevaluación**: responde los quizzes y verifica tu respuesta al instante.
- **Celdas de código**: ejecuta Python real en el navegador con un clic en `▶`.
- **Exportar a PDF**: botón `🖨 guardar PDF` para llevarte la guía impresa.
